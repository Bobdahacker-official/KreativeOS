# KreativeOS 0.2 design and implementation

| Area | Decision |
| --- | --- |
| Adaptive navigation | A two-column launcher on phones, wider layouts when space permits, a persistent bottom dock, and clear page indicators. The launcher keeps a user's chosen order and uses the first two positions for shortcuts. [Material Design 3 compact layouts](https://m3.material.io/foundations/layout/breakpoints/compact) · [Android adaptive layout guidance](https://developer.android.com/design/ui/mobile/guides/layout-and-content/adapt-layout) |
| Touch and motion | Use generous app hit targets and keep navigation near the bottom. Horizontal swipes track the finger and settle into a page after release. The page indicators and keyboard arrows provide alternatives. [Android accessibility guidance](https://developer.android.com/guide/topics/ui/accessibility/apps) · [Apple gesture guidance](https://developer.apple.com/design/human-interface-guidelines/gestures) |
| Rendering | PlutoVG antialiases shapes and strokes in the framebuffer. Glyphs use DejaVu with antialiased masks. This combination works on the two existing framebuffer boot targets. LVGL and Qt Quick were also considered for full widget stacks. [PlutoVG](https://github.com/sammycage/plutovg) · [LVGL Linux framebuffer](https://docs.lvgl.io/master/details/integration/embedded_linux/drivers/fbdev.html) · [Qt embedded Linux](https://doc.qt.io/qt-6/embedded-linux.html) |
| Terminal | A Linux PTY provides the controlling terminal, process I/O and window size. Libvterm models the terminal screen, ANSI colors, cursor, scrollback, and alternate screen. [Linux forkpty](https://man7.org/linux/man-pages/man3/forkpty.3.html) · [libvterm API](https://github.com/neovim/libvterm/blob/nvim/include/vterm.h) |
| Accounts | The first boot creates an owner account. Linux UIDs, private home directories, yescrypt hashes, and a root-only account file separate users. The owner password authorizes additional accounts. [Linux shadow format](https://man7.org/linux/man-pages/man5/shadow.5.html) · [libxcrypt](https://github.com/besser82/libxcrypt) |
| Networking | Linux Ethernet drivers and BusyBox DHCP provide wired configuration. WPA Supplicant provides the Wi-Fi control interface for scanning and association. The image includes selected Intel, Broadcom, and Realtek firmware. [WPA Supplicant](https://w1.fi/wpa_supplicant/) · [Linux wireless drivers](https://wireless.docs.kernel.org/en/latest/en/users/drivers.html) |
